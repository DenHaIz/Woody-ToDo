# Woody — передача проекта

Состояние на **v0.3** (30.10.2026). Репозиторий: https://github.com/DenHaIz/Woody-ToDo, ветка `main`, релизы с APK — во вкладке Releases.

## Что это
Ежедневник для Android 12+ (minSdk 31): задачи на день, повторы, чек-листы, напоминания.
Главные требования владельца: плавные пружинные анимации, скругления, «жидкое стекло», **ноль работы в фоне**, интерфейс на русском, минимум кнопок.

## Стек
Kotlin 2.4 (встроенный Kotlin AGP 9.4), Jetpack Compose (BOM 2026.09), Material 3, Room 2.8 (KSP), DataStore,
[Haze 2.0.1](https://github.com/chrisbanes/haze) — модуль `haze-glass` (жидкое стекло на AGSL, на Android 12 — упрощённый fallback).
DI ручной (`AppContainer`), навигации нет — один экран + оверлеи. Версии — в `gradle/libs.versions.toml`.

### Модель данных
- Задача хранит дату начала и правило повтора (`NONE / DAILY / WEEKLY(маска дней) / EVERY_N_DAYS / MONTHLY`).
- Выполнение, пропуск и отметки подзадач хранятся **по дням** (`completions`, `skips`, `subtask_checks`) — одинаково для разовых и повторяющихся задач.
- Просроченные — разовые задачи из прошлого без отметки; показываются только на «сегодня».
- ⚠️ Room `version = 1`, `exportSchema = false`, миграций нет. Любое изменение сущностей = поднять версию и написать `Migration`, иначе у пользователей упадёт приложение.

### Интерфейс и жесты
- **Одна кнопка «+»** (`WoodyFab`): касание — новая задача, удержание — настройки. Подсказка про удержание показывается, пока пользователь ни разу им не воспользовался (`menu_hint_seen` в DataStore).
- **Лист** (`GlassSheet`): появляется от кнопки, закрывается свайпом вниз из любого места (NestedScrollConnection: остаток прокрутки вниз тянет лист), тапом по фону, «назад» с предпросмотром.
- **Свайп карточки** (`SwipeableTaskCard`): вправо — готово/вернуть, влево — на завтра / пропустить повтор / удалить выполненную. Три стиля из настроек: «Классика», «Капля», «Книжка». Подложка рисуется только вне карточки (карточки полупрозрачные).
- **Стекло** (`liquidGlass`): без отклика на касание (давал сильный засвет). Нажатия подсвечивает `bouncyClickable(glowColor = …)` — мягкий отсвет цвета кнопки.
- Шапка дня меряет высоту *снаружи* `statusBarsPadding` — иначе список уезжает под неё. Заголовки — `FitText` (сжимается в одну строку), названия задач — `LineBreak.Heading`.
- Мало задач в дне (≤ 3) — карточки крупнее (`TaskCard(large = true)`).

### Батарея
Нет сервисов, WorkManager, сети и wake lock. Для задачи с напоминанием ставится один `setExactAndAllowWhileIdle` на ближайшее срабатывание, после него — следующий. После перезагрузки/смены времени будильники восстанавливает `RescheduleReceiver`. Без разрешения на точные будильники — `setAndAllowWhileIdle` (возможна задержка).
Канал уведомлений `reminders_knock` со звуком `res/raw/woody_knock.wav` (звук канала нельзя сменить — при замене звука нужен новый id канала).

### Логотип и звук
- Логотип — **оригинальный** пиксельный дятел, а не копия Woody Woodpecker (персонаж Universal; владелец сначала просил избежать проблем с авторскими правами). Не делать «узнаваемую копию» персонажа.
- Генераторы: `tools/pixel_logo.py` (пиксель-карта → векторные иконки), `tools/knock_sound.py` (синтез стука).

## Сборка на сервере разработки
Сервер общий: **весь тулчейн лежит в `.toolchain/` внутри проекта** (JDK 21, Android SDK, кэш Gradle, GitHub CLI), ничего глобально не ставить.
`env.ps1` (не в git) задаёт переменные только для текущего окна PowerShell; пути 8.3, потому что Robolectric ломается на пробеле в «Android TODO».

```powershell
. .\env.ps1
.\gradlew.bat testDebugUnitTest                  # логика + жесты (Robolectric)
.\gradlew.bat testDebugUnitTest -Pscreenshots    # снимки экранов -> app\build\outputs\roborazzi
.\gradlew.bat lintDebug assembleRelease
.\gradlew.bat --stop
```
Эмулятора нет (VMware без вложенной виртуализации) — визуальная проверка только скриншотами Robolectric, они имитируют статус-бар и навигацию.

## Тесты
- `domain/*Test` — повторы, сборка дня, расчёт напоминаний.
- `ui/InteractionTest` — настоящие жесты: свайпы во всех стилях, короткий свайп, закрытие листа из середины, удержание «+».
- `screenshots/ScreenshotTest` — экраны и покадровые свайпы (только с `-Pscreenshots`).

## Релиз
1. Поднять `versionCode`/`versionName` в `app/build.gradle.kts`.
2. Тесты, lint, `assembleRelease`.
3. Коммит автора **DenHaIz <denister173@gmail.com>** (задан в локальном git-конфиге), без упоминания Claude; тег `vX.Y`; push.
4. `gh release create vX.Y Woody-X.Y.apk --repo DenHaIz/Woody-ToDo --title "Woody X.Y" --notes-file …` — описание коротким списком на RU и EN.

Release подписан **debug-ключом** из `.toolchain/android-user-home/debug.keystore`. Его нельзя терять: другим ключом обновление поверх установленной версии не встанет.
