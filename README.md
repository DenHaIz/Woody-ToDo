**RU** — Ежедневник для Android 12+: задачи, повторы, чек-листы, напоминания, виджет. Дату и время можно писать прямо в названии: «спортзал завтра в 18».

**EN** — A daily planner for Android 12+: tasks, repeats, checklists, reminders, widget. Put the date and time right in the title: "gym tomorrow at 6pm".

## Установка / Install

APK — в [Releases](https://github.com/DenHaIz/Woody-ToDo/releases/latest).

**RU** — Свайп вправо — готово, влево — на завтра. Удержание «+» — настройки. Если напоминания не приходят: Настройки → Напоминания → «Постоянное уведомление».

**EN** — Swipe right — done, left — tomorrow. Hold "+" for settings. If reminders don't arrive: Settings → Reminders → "Persistent notification".

## Сборка / Build

`.\gradlew.bat assembleRelease` · для разработчиков / for developers: [HANDOFF.md](HANDOFF.md)
